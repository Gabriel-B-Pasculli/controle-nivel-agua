# Controle de Níveis de Água

Sistema simples de monitoramento de reservatório utilizando Python e a biblioteca Colorama.

## Funcionalidades

- Exibe níveis do reservatório
- Utiliza cores para representar cada situação
- Simula um sistema real de alerta

## Tecnologias

- Python
- Colorama

## Como executar

1. Instale a biblioteca:
   pip install colorama

2. Execute o programa:
   python main.py
